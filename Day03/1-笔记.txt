JavaScript 一门具有函数式优先编程语言 
    组成：ECMScript 核心js （数组 函数 对象 变量 设计模式 原型 内置函数 内置对象）
    DOM(Document Object Model)文档对象模型 键盘事件 鼠标事件 和网页交互
    BOM(Browser Object Model) 浏览器对象模型 location history ajax 和浏览器做交互 

    运行环境：
    1.nodejs环境
    2.浏览器 

    特点：
    1.需要解析器解析执行 
    2.按照代码解析顺序从上到下依次执行 
    3.是一门弱类型语言（可以重复声明，可以重复赋值） 
        强类型语言 java
    4.大小写敏感

    变量/标识符声明规则：
    1.变量由字母、数字、下划线、$组成
    2.不能以数字开头 
    3.不能使用关键字和保留字
        break class
    4.建议使用驼峰式命名 firstName  

    声明变量方式有哪些？区别？
    var(es5)                let const(es6) 
    js数据类型？
        基本数据类型(简单数据类型):number string boolean null undefined symbol bigint
        引用数据类型(复杂数据类型):Object对象

Gitee 代码版本控制工具 作业练习
    第一次使用首先需要全局配置:
        git config --global user.name "willsonkang1"
        git config --global user.email "2681091754@qq.com"
    将本地代码推送到远程个人仓库：
    第一次提交：
       git init  初始化本地文件夹为git仓库
       首次需要将本地仓库和远程仓库进行绑定
       git remote add origin https://gitee.com/willsonkang1/personal-k.git   
       查看是否绑定成功
       git remote -v
       将更改/新增文件提交到暂存区 git add .
       查看git提交状态 git status 
       将暂存区文件提交到本地仓库 git commit -m 'xxxxx'
       将本地仓库代码推送到远程仓库 git push origin master

    后续更改了文件或者代码 
    后续提交了:
        git add . 将更改/新增文件提交到暂存区
        git status  查看git提交状态
        git commit -m 'xxx' 将暂存区文件提交到本地仓库
        git push origin master 将本地仓库代码推送到远程仓库
